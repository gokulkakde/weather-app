# Weather Lookup

A tiny city weather app for Cursor Challenge 1. One HTML page, a little JavaScript, and [Open-Meteo](https://open-meteo.com/) (no API key).

## Run it

Open `index.html` in a browser, or from this folder:

```bash
python -m http.server 5500
```

Then visit http://127.0.0.1:5500

Search a city, toggle °C/°F, and switch light/dark theme.
